Flux bootstrap on GKE
=====================
Cluster: grafana-assessment, ornate-artifact-414911, europe-west2-a.
Operator chart: 0.61.0. Flux controllers: 2.9.6.
Git source: public https://github.com/michaelalinks/iso-grafana-install.git
Branch: feat/flux-bootstrap. Path: flux.
No Git authentication secret is required for this public repository.

Bootstrap commands (after Terraform creates the cluster)
-------------------------------------------------------
gcloud components install gke-gcloud-auth-plugin
gcloud container clusters get-credentials grafana-assessment --project=ornate-artifact-414911 --zone=europe-west2-a --dns-endpoint
helm upgrade --install flux-operator oci://ghcr.io/controlplaneio-fluxcd/charts/flux-operator --version 0.61.0 --namespace flux-system --create-namespace --wait --timeout 3m
kubectl apply -f flux/flux-system/flux-instance.yaml

If the auth plugin is not on PATH, add the Google Cloud SDK bin directory
printed by gcloud info to PATH, or set its absolute exec-command in the
GKE kubeconfig user entry. No credentials belong in the Git repository.

The initial FluxInstance is applied once; subsequent reconciliation manages
it from Git. The test namespace is NOT applied manually. Flux builds
flux/kustomization.yaml and its nested installs/test-namespace Kustomization,
then creates iso-flux-test. Four controllers are installed; image automation
controllers are omitted because the assignment does not require them.

Verification
------------
kubectl -n flux-system get fluxinstances,gitrepositories,kustomizations
kubectl -n flux-system get deployments
kubectl get namespace iso-flux-test --show-labels

Ready=True on the FluxInstance, GitRepository and Flux Kustomization, plus
an Active iso-flux-test namespace, proves the Git-to-Kustomize path works.
FluxInstance owns the initial sync resources. Do not create duplicate
GitRepository/Kustomization objects for the same root path.

When the implementation branch is merged, change the FluxInstance sync
ref to refs/heads/main and apply that change before deleting the branch.
Terraform and local state are excluded by .gitignore. The existing deleted
README.md is intentionally not included in this bootstrap commit.
